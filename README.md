# Asurants-Hackpad
A simple 6 key macropad meant for day to day usage.
Is capable of going back, forward, and refreshing a browser tab and is also capable of undoing, redoing, finding words (ctrl + f).

It was made using the Blueprint Hackpad tutorial from Hack Club.
https://blueprint.hackclub.com/r/56?ref=r
